About — Why I Built TICKR
I'm Asher, 15, from NYC. Passionate about math + markets — quant is the perfect intersection.

Full-stack from scratch: 100% real yfinance only — no fake prices. Uses fast_info.last_price + individual history with curl_cffi to bypass Yahoo blocking on Render. Batch download kept failing, so I switched to per-ticker fetches with retries.

Quant Lab: LightGBM + XGBoost ensemble, 20 factors (momentum, mean-reversion, volume, volatility), Kelly sizing 12% cap, kill switches. Plain-English explanations first, then technical details. Isolated so it can't crash Portfolio.

What I learned: Finance API integration is hardest — slow info calls, rate limits, Yahoo blocking cloud IPs. Solution: fast_info > history, per-ticker not batch, isolation so one part never crashes another.

What makes it different: Easy, not scary for beginners. Hover to edit holdings, total cost input (not avg), real company names from yfinance, liquid glass design, primary/secondary color pickers with auto black/white text via luminance.

Next: Mobile app + real trading assisted by mini quant, with paper trading validation first.

Robot looks at 20 chart clues (is it far from average? overbought? volume spike? near 20-day high?) then guesses which stocks might bounce next 5 days. It only uses Yahoo price/volume — no news, no fake data. Paper Trading buys with fake money to test if it works. If it loses, you lose nothing.
